# Lecture 02 – Hearing and Seeing Aliasing

## Objective
Investigate how sampling frequency affects a 7 kHz audio tone, using MATLAB waveform plots, FFT amplitude spectra, and playback at each sample rate.

## Experiment
The tone is `sin(2*pi*7000*t)`. It is sampled independently at 48,000, 16,000, 12,000, and 8,000 samples per second. These sample rates are **chosen for this demonstration**; the provided assignment excerpt did not specify which rates to test. The script intentionally does **not** apply an anti-aliasing filter, allowing aliases to appear.

## Nyquist analysis
For a 7,000 Hz sine wave, the Nyquist limit is 14,000 samples per second. To represent this tone unambiguously, use a sampling frequency **greater than** 14 kHz and an adequate analogue anti-aliasing filter in real hardware.

| Sampling frequency | Nyquist frequency | Expected apparent tone | Interpretation |
|---|---:|---:|---|
| 48,000 Hz | 24,000 Hz | 7,000 Hz | No aliasing |
| 16,000 Hz | 8,000 Hz | 7,000 Hz | No aliasing |
| 12,000 Hz | 6,000 Hz | 5,000 Hz | Aliasing |
| 8,000 Hz | 4,000 Hz | 1,000 Hz | Aliasing |

For a pure tone, the apparent frequency is the absolute frequency distance to the nearest integer multiple of the sampling rate, folded into the Nyquist interval: `f_alias = abs(f0 - round(f0/Fs)*Fs)`.

## Results to verify in MATLAB
The `sampled_waveforms.png` plot compares the original 7 kHz reference with sample locations. The `aliasing_spectra.png` plot displays each recording's FFT spectrum. The `aliasing_summary.png` figure compares apparent frequencies.

For 12 kHz sampling, the expected alias is `abs(7000 - 12000) = 5000 Hz`; for 8 kHz sampling, it is `abs(7000 - 8000) = 1000 Hz`. The script prints the measured FFT peak frequency and amplitude. Confirm these values in your own run.

## Listening and engineering interpretation
Listen to the recordings at unchanged playback gain and note whether the tone becomes lower pitched for 12 kHz and 8 kHz sampling. Actual audibility depends on the speaker/headphones and listener. A real recording system should sample above twice the highest useful signal frequency and use anti-aliasing before sampling. Digital anti-alias resampling is different from intentionally sampling a tone too slowly: a proper resampling filter would suppress out-of-band energy instead of keeping a strong alias.
